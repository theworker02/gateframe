# gateframe

Gate encode/decode helpers for frame payloads in pipelines.

**Site:** https://theworker02.github.io/gateframe/

## Install / run

```bash
git clone https://github.com/theworker02/gateframe.git
cd gateframe
node src/cli.js
node --test
```
